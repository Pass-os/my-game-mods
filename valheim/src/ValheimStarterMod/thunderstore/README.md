# Valheim Starter Mod

Mod base de exemplo. Substitua este texto pela descricao real antes de publicar.

## Instalacao

Use o Thunderstore Mod Manager / r2modman, ou copie `ValheimStarterMod.dll`
para `BepInEx/plugins`.

## Configuracao

O arquivo `BepInEx/config/com.pass-os.valheimstartermod.cfg` e gerado no
primeiro boot.

| Opcao | Padrao | Descricao |
| --- | --- | --- |
| `Geral / Enabled` | `true` | Liga/desliga o mod |
| `Jogador / StaminaRegenMultiplier` | `1.0` | Multiplicador da regen de stamina |
| `Debug / VerboseLogging` | `false` | Logs extras no console |
